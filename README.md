# Tomato Plant Disease Detection System 🍅

An AI/ML-based computer vision pipeline designed to recognize and classify diseases in tomato plants from leaf images. This project addresses agricultural challenges using deep learning.

## 🌟 Key Features
* **Deep Learning Classification:** Trained an EfficientNetB0 model to identify multiple plant disease strains accurately.
* **End-to-End Pipeline:** Full data preprocessing, model training evaluation, and deployment workflow.
* **User Interface:** Interactive web dashboard for seamless image uploads and instant predictions.

## ⚙️ Tech Stack
* **Core Language:** Python
* **Machine Learning:** TensorFlow, Keras, OpenCV
* **Web Framework:** Flask, HTML, CSS

## 📁 Repository Structure
* `/app.py` - Flask application entry point
* `/models/` - Trained EfficientNetB0 model files
* `/templates/` - HTML user interface sheets
* `/requirements.txt` - System dependencies

## 🔧 Installation & Local Setup
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Install the necessary packages:
   ```bash
   pip install -r requirements.txt
   ```
3. Boot the Flask local server:
   ```bash
   python app.py
   ```
